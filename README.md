# HomeWork\_UE5

Домашние задание по Unreal Engine ver 5.8



ДЗ №1

1\) Скачать Git (либо GitHub Desktop, либо аналог)

2\) Зарегистрироваться на GitHub (либо аналог)

3\) Создать проект (желательно пустой)

4\) Создать .gitignore

5\) Инициализовать репозиторий

6\) Прислать ссылку на публичный репозиторий с ФИО в чат



ДЗ №2

1\) Организовать структуру проекта

2\) Создать Blueprint типа Actor и Blueprint типа Character. (Дать им адекватные имена)

3\) Создать по 3 переменных (Variables) в каждом Blueprint, различного типа. 

4\) Добавьте компоненты (Components) к каждому Blueprint.



ДЗ №3

1\) Создайте ВР класса Actor с триггером, который считает сколько раз его пересекли.

2\) Модифицируйте ваш Actor таким образом, что когда его пересекает другой Actor, визуально менялось какое-то его состояние (например, цвет лампочки, её включение/отключение, положение компонента и т.п.).

3\) Создайте DataTable для хранения информации об объекте, заполните её информацией. И на BeginPlay пусть выводится значение из таблицы.

4\) Модифицируйте ваш триггер таким образом, чтобы при пересечении его выводилась какая-то информация из DataTable через FormatText.

5\) Создайте любую математическую функцию(!), которая бы считала что-то из входных параметров и выдавала результат на экран. 

6\) Создайте массив данных (цифровых), который бы в цикле считал сумму этих данных. Выводить на экран только результат. 

7)\* Сделайте так, чтобы триггер при пересечении менял своё состояние. Это состояние должно быть записано в Enum, который рандомится и используется для дальнейшего пересечения. 

8)\* Создайте Actor-лифт, каждый раз, когда что-то пересекает его триггер, лифт поднимается и опускается до определённых точек. Сделайте так, чтобы пока лифт движется, его нельзя было заново активировать.
